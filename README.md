## 🔁 一条完整的 FDE 路线

```text
🧭 找到工位
   ↓
🧠 学习岗位方法与案例学习
   ↓
📚 阅读脱敏案例，理解约束
   ↓
🛠️ 使用工具和模板拆解问题
   ↓
📋 按 SOP 组织交付与交接
   ↓
🧪 用最小 Demo 验证方案
   ↓
📊 用报告与指标复盘结果
   ↓
🤝 在社区讨论、协作和持续迭代
```

这不是必须从头走到尾的课程顺序。你可以从任何一站开始，再沿着上游补知识、沿着下游做验证。

## 🏗️ GoldenTellus 三层架构

```text
理论层：建立认知、方法、外部参照与行业判断
实践层：把方法变成案例、工具、流程和可运行验证
治理层：提供总入口、协作规则和组织公共资料
```

## 📌 使用原则

- 不确定去哪：先回到本仓库，再按“有需求？从这里直达”选择路径。
- 先看 README 和模板，再提交内容或创建 Demo。
- 案例必须有来源、授权状态、脱敏说明，并区分事实、估算和推断。
- Demo 不提交 API Key、客户原始数据、个人敏感信息或未经授权的第三方资产。
