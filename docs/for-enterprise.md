# 🏢 企业入口

企业做 AI，不是先选模型，而是先决定：哪个业务问题值得解决、条件是否具备、试点验证什么、如何验收，以及是否应扩大。

| 你现在的阶段 | 要回答的问题 |
|---|---|
| 选业务场景 | 这个问题是否高频、可度量、有明确负责人？不做 AI 是否也能解决？ |
| 检查准备度与风险 | 数据在哪、质量如何？涉及哪些系统、权限、安全和合规约束？ |
| 批准试点 | 试点范围、成功指标、时间和预算上限是什么？失败时如何止损？ |
| 交付与验收 | 谁来验收、用什么数据验收？上线后谁负责运营？ |
| 运营与扩大 | 成本、质量和使用情况是否达标？复制到其他场景需要改什么？ |

想看这些问题在真实项目里怎么被回答，去 [📚 案例库](cases/index.md)。

公开案例和 Demo 不构成项目结果承诺。具体项目仍需独立完成需求、数据、安全、合规、成本、采购和验收评估。
