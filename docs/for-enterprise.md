# 🏢 企业入口

企业做 AI，不是先选模型，而是先决定：哪个业务问题值得解决、条件是否具备、试点验证什么、如何验收，以及是否应扩大。

从 [🏢 goldentellus-enterprise](https://github.com/GoldenTellus/goldentellus-enterprise) 开始，它会按决策阶段把你带到相应的案例、流程、工具和 Demo。

| 你现在的阶段 | 推荐下一站 |
|---|---|
| 还不知道该从哪里开始 | [开始前：找到当前决策阶段](https://github.com/GoldenTellus/goldentellus-enterprise/blob/main/guides/00-start-here.md) |
| 正在选业务场景 | [选择业务问题](https://github.com/GoldenTellus/goldentellus-enterprise/blob/main/guides/01-choose-a-business-problem.md) |
| 需要确认数据、系统、安全或合规条件 | [检查准备度与风险](https://github.com/GoldenTellus/goldentellus-enterprise/blob/main/guides/02-check-readiness-and-risk.md) |
| 准备批准试点 | [批准一个受控试点](https://github.com/GoldenTellus/goldentellus-enterprise/blob/main/guides/03-approve-a-pilot.md) |
| 正在上线、验收或复盘 | [交付、上线与验收](https://github.com/GoldenTellus/goldentellus-enterprise/blob/main/guides/04-deliver-and-accept.md) → [运营、复盘与扩大](https://github.com/GoldenTellus/goldentellus-enterprise/blob/main/guides/05-operate-and-scale.md) |

公开案例、Demo 和报告不构成项目结果承诺。具体项目仍需独立完成需求、数据、安全、合规、成本、采购和验收评估。

联系渠道：待确认。确认前请在 [🤝 goldentellus-community Discussions](https://github.com/GoldenTellus/goldentellus-community/discussions) 交流，或通过公开 Issue 维护。公开渠道不要提交客户名称、个人信息、原始生产数据、凭据或其他未脱敏材料。
