## 🛡️ 社区原则

!!! note "先把边界说清楚"
    区分事实、估算、推断和观点；案例公开前完成授权、脱敏和许可证检查；Demo 不提交密钥、客户原始数据或未经授权的第三方资产。

!!! tip "从一个交接物开始"
    一篇经过来源标注的文章、一个能启动的 Demo、一份清晰的 SOP，都是连接上下游工位的有效贡献。
