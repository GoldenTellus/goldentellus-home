# GoldenTellus FDE Pipeline Community

> 我们不培养六边形战士。FDE 不是一个角色，是一条流水线。

GoldenTellus 是一个围绕 AI 应用落地建立的开放社区，连接知识、案例、Demo、交付模板与资源网络。

## 从这里开始

- [新人入口](for-beginner.md)：找到适合你的工位和第一条学习路径。
- [FDE 入口](for-fde.md)：从诊断、架构、开发、数据、集成或运营阶段开始协作。
- [企业入口](for-enterprise.md)：查看脱敏案例、Demo 和交付边界。
- [仓库导航](navigation.md)：按目标进入对应仓库。

## 社区原则

- 区分事实、估算、推断和观点。
- 案例公开前完成授权、脱敏和许可证检查。
- Demo 不提交密钥、客户原始数据或未经授权的第三方资产。
- 用清晰的交接物连接不同工位。
